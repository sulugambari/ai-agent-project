A plain-English look at Northstar

Meet the assistant that knows what it's allowed to tell you

Northstar Labs built an AI helper that answers questions using the company's own files. The interesting part isn't the answers — it's how carefully it decides what it's allowed to say, to whom.

"Tested again and again — and it has never once shown someone a file they weren't allowed to see."
That's the one promise this whole project had to keep.

The everyday problem

A customer calls, asking when their order is arriving. One employee remembers promising Tuesday. Nobody remembers that a colleague already emailed the customer a new date — because something changed.

Whoever answers next has two choices: repeat the old promise and sound confident, or dig through emails, chats and documents to find out what's actually still true. Most people don't have twenty minutes to dig. Northstar's whole job is to do that digging in seconds — and to know which answer is the real one.

Four things it always does

However clever the answer sounds, these four rules never bend.

Always shows its sources

Every answer links back to exactly where it came from, so you can check it yourself instead of taking its word for it.

Only shows you what's yours to see

Two people can ask the exact same question and get different answers — because it checks who's allowed to see what before it even starts looking.

Says "I don't know" instead of guessing

If the answer isn't in the company's records, it says so plainly — rather than inventing something plausible-sounding.

Never acts on its own

It can prepare something, like a request to a colleague — but a real person has to click approve before anything actually happens.

The trickiest moment we found

A private HR file had a handwritten-style note inside it that basically said, "don't show this to other departments." Sensible, except for one thing.

One day, the one person who actually was allowed to see that file asked for it — and Northstar read the note and said no anyway, to the very person it was meant for.

It's a bit like a filing cabinet with a sticky note reading "ask my manager first" — and the manager is the one standing right there asking. We fixed it by making sure the rule about who's allowed to see what always comes from official company policy, never from a note written inside the file itself.

"Sorry — that's not something your role can access."

"Can I see the confidential HR file?"
"Here's the file you asked for."

Same question, two different people — two different, and correct, answers.

Is it ready?

Yes, with some fine print.

The tests that matter most have all passed, repeatedly: it has never shown someone a file they shouldn't see, and it never takes an action without a person's OK.

What's still unfinished is homework, not trust: a few side-by-side comparisons we ran out of time to complete, and a bit more everyday feedback to collect. Nothing that changes the promises above — just more evidence before anyone calls it done.
